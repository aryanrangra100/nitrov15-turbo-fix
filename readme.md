# Nitro V Turbo Fix

A fix/mod for **Acer Nitro V** laptops running **NitroSense 5.1.x.x**.

> ⚠️ **Recommended:** Use this mod with **NitroSense 5.1.x.x**.
> Other NitroSense versions have not been tested.

## 🧪 Tested NitroSense Version

* **NitroSense v5.1.385**

## 💻 Tested Devices

| Device                       | CPU                  | GPU      |
| ---------------------------- | -------------------- | -------- |
| Acer Nitro V15-51 (ANV15-51) | Intel Core i7-13620H | RTX 4050 |
| Acer Nitro V15-52 (ANV15-52) | Intel Core 5         | RTX 4050 |

These are the devices on which the fix has been tested successfully.

## ⚡ Performance Mode & Fan Behavior

> ⚠️ **Important:** The Turbo/Performance modes shown by the modified NitroSense interface are **visual only**. The **last actual performance mode applied** will remain in effect.

### Fan Behavior

| Mode        | Fan Speed |
| ----------- | --------: |
| Auto        | Automatic |
| Balance     | ~5000 RPM |
| Performance | ~6000 RPM |
| Turbo       | ~7000 RPM |

The displayed mode does **not necessarily mean that NitroSense has actually applied a different performance profile**.
